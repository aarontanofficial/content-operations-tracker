# Content Operations Tracker

Personal PWA for tracking Facebook content tasks (no Meta API). Hosted on GitHub Pages, data in Supabase with Row Level Security.

Setup: 1) run supabase-schema.sql in Supabase SQL Editor, 2) put your Supabase URL and publishable key in index.html, 3) enable GitHub Pages (Settings > Pages > main / root).

Never commit a Supabase secret or service-role key.
